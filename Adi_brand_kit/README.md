# Aditya Portfolio Brand Kit

Primary identity: ADITYA — SOFTWARE ENGINEER

## Files
- `png/aditya-logo-primary.png` — transparent primary logo
- `png/aditya-logo-light-bg.png` — dark-text variant for light backgrounds
- `png/aditya-mark.png` — transparent monogram/mark
- `png/*1600.png` — high-resolution primary logo
- `svg/aditya-logo-primary.svg` — scalable primary logo
- `svg/aditya-logo-light-bg.svg` — scalable light-background variant
- `svg/aditya-mark.svg` — scalable mark/icon
- `svg/aditya-wordmark.svg` — horizontal wordmark
- `favicons/` — common favicon sizes
- `social/` — ready-to-use social/avatar images

## Suggested usage
- Portfolio navbar: `aditya-wordmark.svg`
- Hero/landing page: `aditya-logo-primary.svg`
- Favicon/browser tab: `favicons/icon-32.png` or `icon-16.png`
- GitHub/social avatar: `favicons/icon-512.png` or `social/avatar.jpg`
- Light UI: `aditya-logo-light-bg.svg`
- Dark UI: `aditya-logo-primary.svg`

Brand colors:
- Cyan: #22D3EE
- Blue: #2563EB
- Violet: #C026D3
- Dark: #050914
